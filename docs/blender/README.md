# Blender

This folder contains the Blender material export and bake notes.

- [Workflow](workflow.md): CLI use, graph export, native MaterialX, baking, colour management, and troubleshooting.
- [Poly Haven corpus](polyhaven-corpus.md): reproducibility record for the CC0 image-texture bake corpus.
- [Free procedural corpus](free-procedural-corpus.md): reproducibility record for the external procedural-material bake corpus.

The records keep source assets and renders out of the repository. Recreate them with the commands in the linked documents when Blender, Houdini, OCIO, bake logic, or USD authoring changes.
